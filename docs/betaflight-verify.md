# Betaflight 수신 검증 절차 (Phase 5)

> ⚠️ **모든 단계는 프롭(프로펠러) 제거 상태에서 진행한다.**

전제: Phase 4 완료 — 트레이너 스위치(SH)로 PC 입력 ↔ 스틱 전환이 동작하는 상태.

## 0. 준비

- 드론 배터리 연결 (프롭 제거 확인!)
- ELRS 바인딩 완료, 조종기 ↔ 드론 링크 확립 (조종기에서 텔레메트리 확인)
- PC: Betaflight Configurator 실행, FC를 USB로 연결

## 1. Receiver 탭 검증

1. Configurator → **Receiver 탭** 열기
2. 조종기 스틱을 움직여 채널 반응 확인 (기준선)
3. PC에서 `python channel_sweep.py` 실행 + **SH 당김**
4. 확인 항목:
   - [ ] Roll/Pitch/Yaw 막대가 스윕에 따라 움직임
   - [ ] 채널맵이 **AETR** (Channel Map 드롭다운)
   - [ ] 범위: 최소 ~988, 중앙 ~1500, 최대 ~2012
   - [ ] 방향: PC에서 roll=+1.0 보냈을 때 Roll 막대가 오른쪽 끝으로
5. 어긋나는 항목이 있으면 기록 (조종기 Trainer 비율/EdgeTX 출력 범위 조정으로 보정)

## 2. 페일세이프 3종 테스트

각 시나리오에서 **Receiver 탭 채널이 어떻게 변하는지** 관찰:

| # | 시나리오 | 조작 | 기대 동작 |
|---|---|---|---|
| 1 | PC 스크립트 강제 종료 | 스윕 중 Ctrl+C / 프로세스 킬 | 0.5초 내 조종기 스틱 값으로 복귀 (Pro Micro 타임아웃 → EdgeTX 스틱 복귀) |
| 2 | 트레이너 스위치 해제 | 스윕 중 SH 놓기 | 즉시 스틱 값으로 복귀 |
| 3 | USB 물리 분리 | 스윕 중 Pro Micro USB 뽑기 | 0.5초 내 스틱 값으로 복귀 |

- [ ] 세 경우 모두 **채널이 프리즈되거나 튀지 않고** 스틱 값으로 넘어가는지 확인
- [ ] 추가: 조종기 전원 OFF → Betaflight 자체 페일세이프(Failsafe 탭 설정: Drop 권장) 발동 확인

## 3. ARM 테스트 (props off)

1. ARM 스위치는 **조종기 물리 스위치** (PC 제어 아님 — 설계 원칙)
2. 순서: 스로틀 최소 확인 → ARM → 모터 회전 확인
3. SH 당겨서 PC 제어로 전환 → PC에서 스로틀을 **아주 조금** 올려 모터 RPM 변화 확인
4. SH 놓기 → 스틱 제어 복귀 확인 → DISARM

- [ ] PC 스로틀 입력에 모터가 반응
- [ ] SH 놓으면 즉시 스틱 스로틀로 복귀
- [ ] DISARM 정상
