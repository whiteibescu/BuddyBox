# TX15 Max (EdgeTX) 트레이너 설정 가이드

목표: DSC 포트로 들어오는 PPM(=PC/Pro Micro)을 "학생(Student)" 입력으로 받아,
트레이너 스위치를 누르고 있는 동안만 스틱 4채널을 PC 입력으로 대체.

## 1. 모델 설정 — Trainer 모드

1. 사용할 모델 선택 후 **MDL(모델 설정) → Setup 페이지** 진입
2. **Trainer** 항목을 **`Master/Jack`** 으로 설정
   - Master = 이 조종기가 선생(전파 송신 주체), Jack = 학생 신호가 DSC 잭으로 들어옴

## 2. 시스템 설정 — Trainer 입력 매핑

1. **SYS → Trainer** 페이지 진입
2. 각 채널의 모드와 소스 설정:

| 채널 | 모드 | 비율 | 설명 |
|---|---|---|---|
| Rud (Yaw) | `:=` (Replace) | 100% | PC 입력으로 완전 대체 |
| Ele (Pitch) | `:=` (Replace) | 100% | 〃 |
| Thr (Throttle) | `:=` (Replace) | 100% | 〃 |
| Ail (Roll) | `:=` (Replace) | 100% | 〃 |

   - `:=` (Replace): 트레이너 활성 시 학생 입력으로 **완전 대체** — 자동 제어에 적합
   - `+=` (Add)는 스틱에 더하는 방식이라 이번 용도에는 부적합
3. **캘리브레이션**: PPM 신호가 들어오는 상태(PC에서 모든 채널 중립 1500µs 송신)에서
   Trainer 페이지 하단 **Cal** 버튼으로 중립점 캘리브레이션

> PPM 채널 순서는 펌웨어에서 **CH1=Roll(Ail), CH2=Pitch(Ele), CH3=Throttle(Thr), CH4=Yaw(Rud)** (AETR)로 송신합니다.
> EdgeTX Trainer 페이지의 소스 채널 번호가 이와 일치하는지 확인하세요.

## 3. 트레이너 활성화 스위치

1. **MDL → Special Functions** 페이지 진입
2. 빈 슬롯에 추가:
   - 스위치: **SH↓** (모멘터리 스위치 권장 — 놓으면 즉시 해제됨 = 안전)
   - 기능: **Trainer** (전체) 또는 Trainer Sticks
   - 활성: 체크
3. 이제 **SH를 당기고 있는 동안만** PC가 스틱을 제어하고, 놓으면 즉시 본인 스틱으로 복귀

> 장시간 자율비행 테스트 단계에서는 토글 스위치(SF 등)로 바꿔도 되지만,
> 초기 테스트는 반드시 모멘터리(SH)로 — 손을 떼는 것만으로 제어권 회수.

## 4. 신호 확인

1. Pro Micro 연결 + PC에서 테스트 스크립트 실행
2. **SYS → Trainer** 페이지에서 각 채널 막대가 PC 입력에 따라 움직이는지 확인
3. 채널 모니터(MDL → 채널 모니터)에서 트레이너 스위치 ON/OFF에 따라 출력이 바뀌는지 확인

## 5. 안전 체크리스트 (비행 전 필수)

- [ ] **프롭 제거** 상태에서 전 과정 검증 완료
- [ ] ARM 스위치는 조종기 물리 스위치에 유지 (PC가 ARM 제어 못 함)
- [ ] 트레이너 스위치 해제 → 즉시 스틱 복귀 확인
- [ ] PC 시리얼 강제 종료(스크립트 kill) → 1초 내 "Trainer signal lost" + 스틱 복귀 확인
- [ ] USB 케이블 물리적 분리 → 스틱 복귀 확인
- [ ] Betaflight 페일세이프(수신기 신호 상실 시 Drop/GPS Rescue) 설정 확인
- [ ] Betaflight Configurator Receiver 탭에서 4채널 방향·범위(988~2012) 확인
